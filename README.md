# 50 sources de Rust da CodeNomad Academy

Este repositório reúne 50 programas completos em Rust, cada um num único arquivo, prontos para compilar e explicados onde importa. Ele serve para quem está aprendendo Rust e quer ler código idiomático de verdade (structs e enums com `impl`, `Option` e `Result` com `?`, traits como `Display` e `FromStr`, iteradores, `HashMap`, `std::fs` e `std::net`), e para quem já programa e quer uma calculadora, um validador, um organizador de pastas, um servidor HTTP ou um jogo de terminal sem adicionar crate nenhuma. Cada source faz uma coisa bem definida, valida a entrada, dá mensagens de erro claras e termina com três exercícios para você continuar. É um projeto da [CodeNomad Academy](https://codenomad.org), plataforma de autoestudo em desenvolvimento de software.

## Como rodar

Requisito: Rust 1.70 ou mais novo (edição 2021). Nada além da biblioteca padrão. Não há `[dependencies]`, não há download durante a compilação. Os 50 arquivos foram conferidos com `rustc 1.97.1` e compilam sem nenhum aviso com `-D warnings`.

Cada source compila direto com `rustc`, sem Cargo. Compilar e rodar com argumentos reais:

```bash
rustc -O --edition 2021 -D warnings sources/01_calculadora_juros_compostos.rs -o juros.exe
./juros.exe 1000 0,8 24 200
```

Rodar a demonstração da mesma source:

```bash
./juros.exe --demo
```

No Linux e no macOS troque `juros.exe` por `juros` nos dois comandos: o nome da saída é você quem escolhe com `-o`.

A flag `--demo` executa uma demonstração completa com dados de exemplo, sem pedir nada no teclado e sem acessar a internet. Ela termina sozinha em poucos segundos e é o jeito mais rápido de ver o que o programa faz antes de ler o código.

Sem argumento nenhum, o programa mostra o uso. Os jogos (46 a 50), sem argumentos, entram no modo interativo. Os caminhos nos exemplos partem da raiz do repositório.

Se preferir o Cargo, o [Cargo.toml](Cargo.toml) da raiz declara os 50 arquivos como binários. O nome de cada binário é o nome do arquivo sem o número:

```bash
cargo run --release --bin calculadora_juros_compostos -- --demo
cargo run --release --bin calculadora_juros_compostos -- 1000 0,8 24 200
cargo build --release
```

O `cargo build --release` compila os 50 de uma vez e deixa os executáveis em `target/release/`.

## Como este material é organizado

Um arquivo por programa. Cada source vive em `sources/NN_nome.rs`, em que `NN` é o número de 01 a 50. Não há módulos compartilhados nem `lib.rs`: você copia um arquivo e ele compila sozinho.

Cabeçalho padrão. Todo arquivo começa com o mesmo bloco de comentário `//`, com cinco campos: "O que faz", "Como usar" (o comando real de compilação, o comando com argumentos e o comando com `--demo`), "O que você aprende", "Requisitos" e a licença. Dá para saber se a source serve antes de rolar a tela.

Comentários onde importa. Os comentários estão nos pontos em que um aluno costuma tropeçar: por que dinheiro se calcula em centavos inteiros, por que `take()` resolve a briga com o borrow checker numa lista ligada, por que `checked_mul` é melhor do que um estouro silencioso, por que `?` só funciona em função que devolve `Result`. O resto do código fala por si.

Bloco "Para ir além". Cada arquivo termina com três exercícios sugeridos para você estender o programa com o que acabou de ler.

Só biblioteca padrão. Os 50 arquivos usam apenas a `std`: `std::env` para os argumentos, `std::fs` e `std::path` para arquivos, `std::collections` para `HashMap`, `BTreeMap`, `VecDeque` e `HashSet`, `std::net` para o cliente e o servidor HTTP, `std::thread` e `std::time` onde há espera ou medição. Isso é de propósito: você aprende a linguagem, não um framework. Até o SHA-256, o leitor de JSON e o gerador pseudoaleatório estão escritos no próprio arquivo.

Zero avisos. Cada arquivo compila com `-D warnings`, que transforma qualquer aviso do compilador em erro. Nenhum `unwrap()` em caminho que dependa da entrada do usuário: erro de entrada vira uma mensagem "Erro: ..." e código de saída 1, nunca um pânico.

Dois modos em toda source. Com argumentos, o programa faz o trabalho de verdade. Com `--demo`, ele mostra tudo o que sabe fazer sem depender de você.
